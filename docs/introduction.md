# Introduction

> [!NOTE]
> This project and its documentation are a work in progress. Parts of the project and
> the documentation may change and may be outdated.

> [!WARNING]
> This documentation may be outdated or contain installation steps that do not work with
> bitcoinix yet.
> Please report problems at <https://github.com/bitcoinix/bitcoinix/issues>.

**bitcoinix** is a collection of Nix packages and NixOS modules for easily installing
full-featured Bitcoin nodes with an emphasis on security.

It is a community fork of [nix-bitcoin](https://github.com/fort-nix/nix-bitcoin), which was
archived in August 2026. bitcoinix is a community initiative to keep the project maintained
and to continue its development.

* Source code, issues and project overview: [github.com/bitcoinix/bitcoinix](https://github.com/bitcoinix/bitcoinix)
* Original project and historical documentation: [github.com/fort-nix/nix-bitcoin](https://github.com/fort-nix/nix-bitcoin)

The documentation is largely inherited from nix-bitcoin and is being updated step by step.
